# KiCad checklist

- [ ] Team replaces project stubs with native KiCad 8 schematic and PCB.
- [ ] ERC clean or every exception explained.
- [ ] DRC clean or every exception explained.
- [ ] USB D+/D− impedance/routing reviewed.
- [ ] GPIO 19/20 reserved for native USB; flash/PSRAM and strapping pins avoided.
- [ ] Power thermal calculation and fuse/LDO ratings verified from datasheets.
- [ ] Export `.kicad_sch`, `.kicad_pcb`, fabrication files, and logs under `docs/evidence/`.
