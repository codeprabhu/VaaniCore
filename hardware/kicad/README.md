# KiCad Rev A steps

Team must draw the real schematic and layout in KiCad 8. Use `hardware/pinmap.csv` as the reviewed netlist-level source, then run ERC/DRC, export `.kicad_sch`/`.kicad_pcb`, and attach logs under `docs/evidence/`. The block-level reference must be captioned as such and is not a substitute for the team drawing.
