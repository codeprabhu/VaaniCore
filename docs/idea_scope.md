# Idea-document scope extraction

The supplied five-page idea document confirms the intended boundary: an embedded device performs real-time audio acquisition, DSP, lightweight closed-vocabulary AI, intent/context handling, RTOS/DMA work, and structured USB communication; a host agent performs controlled desktop operations; optional larger/cloud AI is future work only. The evaluation must compare local, host, and hybrid workload partitions using latency, utilization, memory, traffic, and power where available.

This repository therefore keeps Wi-Fi, camera, LLM/cloud dependency, unrestricted shell access, and broad natural-language interpretation outside the MUST path. The concrete demonstration remains an electronics-project open-and-simulate workflow.
